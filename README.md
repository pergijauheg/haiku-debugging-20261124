One haiku about debugging, in the 5-7-5 syllable shape, for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
competition on make.fun:

> Breakpoint holds its breath
> one log line confesses all
> it was my typo

## Run it

```sh
python3 main.py
```

`main.py` writes the haiku to `/output/entry.txt` (or to the path in
`OUTPUT_PATH` for a local run). The entry is 3 lines, 70 characters,
inside the competition's 1–200 character gate.
